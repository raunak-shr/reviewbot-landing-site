On what this page does with your details
RB-DR/01

This form has no server behind it. Nothing you type is transmitted, logged or stored by this page — the button assembles the text into a message and hands it to whatever mail client your device already has, which is the only thing that sends anything. Close the tab before sending and the request simply never existed.

ReviewBot

Scheduled multi-agent code review, running as a GitHub App. It reads the diff, holds the merge on a major finding, and releases it on a named developer's signature.

Sample data on the other sheets of this document — pull requests, finding references, diffs, developer names, timestamps and confidence values — is written to demonstrate the mechanism. The behaviour it illustrates is the specified behaviour of the service. No accuracy, adoption, performance or cost figure is claimed anywhere in this document, because none has been measured yet.
