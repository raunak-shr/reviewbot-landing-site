On what this page does with your details
RB-DR/01

Raising the slip posts what you typed to one function on this site, which sends it on as a single email and keeps nothing. There is no database, no analytics on this page and no third party in the path beyond the mail provider that carries the message. Your address is used to reply to you and for nothing else. Close the tab before you raise it and the request simply never existed.

ReviewBot

Scheduled multi-agent code review, running as a GitHub App. It reads the diff, holds the merge on a major finding, and releases it on a named developer’s signature.

Sample data on the other sheet of this document — pull requests, finding references, diffs, developer names, timestamps and confidence values — is written to demonstrate the mechanism. The behaviour it illustrates is the specified behaviour of the service. No accuracy, adoption, performance or cost figure is claimed anywhere in this document, because none has been measured yet.
